# QT Wiki Console

React + Vite front-end for the QT Wiki operation console.

## Run

```bash
npm install
npm run dev
```

The dev server proxies `/api`, `/chat`, `/agent`, and `/health` to `http://127.0.0.1:8000`.

## Build

```bash
npm run build
```

The UI includes mock fallback data, so it can be previewed before every backend endpoint is implemented.
